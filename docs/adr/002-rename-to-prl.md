# 002 — Rename the project to PRL (Prompt Refine Loop)
Date: 2026-10-13
Status: accepted
Context: The project was called OptimizedClaude, which puts the Claude trademark in the
name (Anthropic's legal page forbids using the Claude Code or Anthropic names in a product
name). The short command `ocl` also collides with OpenCL. The interim name PSS collides
with RSA-PSS.
Decision: The project is PRL (Prompt Refine Loop), the repo is `prompt-refine-loop`, the
command is `prl`. Plain-text statements like "works with Claude Code" are still allowed.
Consequences: Docs, prompts, the Python package and the pyproject were renamed. The old
GitHub URL redirects after the repo rename. Not legal advice.
